# 绩点正计算 · 参数提取指令

> 用在「提取参数」节点的【指令】框里。整段复制粘贴。
>
> ⚠️ 这个工具的四个参数都是 **Number + 必填**，所以提取节点必须四个都给，
> 少一个这个节点就调不起来。因此指令里对"没说"的情况给了默认值。
>
> ⚠️ 但默认值只在**用户确实提到了绩点**时才有意义。所以上面的条件节点最好加一条：
> 这句话里出现"绩点/GPA/学分"且有数字，才走这条路。

---

## 指令（整段复制）

```
你是参数提取器。从用户的话里抽出四个数字，只输出数字，不要输出单位、不要解释。

【current_gpa】现在的绩点。0 到 4 之间的小数。
  "我绩点 3.2" → 3.2
  "GPA 3.5" → 3.5
  "现在平均 3.2" → 3.2
  用户说的是百分制分数（比如"平均分 85"）→ 按 (分数 - 50) / 10 粗算，
  85 → 3.5，82 → 3.2，90 → 4.0，75 → 2.5
  用户没说 → 3.0

【completed_credits】已经修完的学分。正整数。
  "已修 80 学分" → 80
  "修了 80 个学分" → 80
  "已经拿到 80 分" → 80
  用户没说 → 90

【remaining_credits】还要修的学分。正整数。
  "还要修 40 学分" → 40
  "还剩 40 个学分" → 40
  "下学期还有 40 分" → 40
  用户没说 → 30

【target_gpa】想达到的绩点。0 到 4 之间的小数。
  "想上到 3.5" → 3.5
  "目标绩点 3.5" → 3.5
  "想冲到 3.5" → 3.5
  用户没说 → 3.5

【硬规则】
1. 四个都必须输出数字，不能是空、不能是"不知道"。
2. 绩点类（current_gpa、target_gpa）必须在 0 到 4 之间；
   学分类（completed_credits、remaining_credits）必须是大于 0 的整数。
3. 百分制换算只对绩点类做，学分不要换算。
4. 用户如果说"还差多少个学分毕业"，那也算 remaining_credits。

【例子】
用户：我现在绩点 3.2，已修 80 学分，还要修 40 学分，想上到 3.5
输出：current_gpa=3.2  completed_credits=80  remaining_credits=40  target_gpa=3.5

用户：我 GPA 3.0 修了 100 个学分，还剩 20 个，想冲到 3.6
输出：current_gpa=3.0  completed_credits=100  remaining_credits=20  target_gpa=3.6

用户：帮我算算绩点 3.2 80 40 3.3
输出：current_gpa=3.2  completed_credits=80  remaining_credits=40  target_gpa=3.3
```

---

## 配好之后自测这三句

1. **"我现在绩点 3.2，已修 80 学分，还要修 40 学分，想上到 3.5"**
   → 3.2 / 80 / 40 / 3.5（用这组数，工具应回"达不到：未来全拿 4.0 也最多到 3.47 分"）

2. **"我 GPA 3.0 修了 100 个学分，还剩 20 个，想冲到 3.6"**
   → 3.0 / 100 / 20 / 3.6
   → 应回"**达不到**：未来课程全拿 4.0 也最多到 **3.17** 分"
      （算一遍：3.0×100 + 4.0×20 = 380，380/120 = 3.167；
        而要到 3.6 需要未来平均 6.6 分，超过 4.0 上限）

3. **"帮我算算绩点 3.2 80 40 3.3"**
   → 3.2 / 80 / 40 / 3.3（应回"理论上可以达到：未来课程平均需要 3.5 分"）

三句都能抽出四个数字，说明提取对了。

---

## 一个提醒

如果用户只说"我想提高绩点"，一句数字都没有，这个提取节点仍会填默认值（3.0 / 90 / 30 / 3.5），
工具会算出一个看着很像那么回事、其实跟用户无关的结果。

**这种答案比答"我不知道"更糟**，所以条件节点那条判断要卡住：
必须句子里同时有"绩点/GPA/学分"**和**数字，才放进来。
