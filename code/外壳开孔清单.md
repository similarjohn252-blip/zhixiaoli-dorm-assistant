# 3D 打印外壳·开孔清单（2026-10-18 ✓）

> ⚠️ **2026-10-27 变更：屏幕已去掉** —— 屏幕窗口那个开孔**不再需要** ✗。
> 其余开孔（麦克风、喇叭、按键、电源灯、Type-C）照旧。
> 电源灯（GPIO11）那个孔要留，它现在是唯一的指示灯。

> 用途：把现在的「面包板 + 飞线」装进外壳时，照这份做 ✓
> ⚠️ 尺寸是**常见模块的标准值** ✓ —— 打印前请用卡尺量一下你手上的实物 ✗（模块批次有差异 ✓）
> ⚠️ 这份只讲**机械与声学** ✓ 不涉及改代码 ✓（引脚不变 ✓ 固件不用动 ✓）

## 一、件清单（来自 `config.h` ✓ 以实车为准 ✓）

| 件 | 型号 | 接口 | 备注 |
|---|---|---|---|
| 主控 | ESP32-S3（N16R8，16MB Flash / 8MB PSRAM） | — | 板上有 **BOOT 键 = GPIO0** ✓（按住可进下载模式 ✓）|
| 屏 | **SSD1306 128×64**，4 针 | I2C（SCL=47, SDA=21） | 屏的**玻璃比 PCB 小** ✓ 见下 |
| 麦克风 | **I2S MEMS**（INMP441 / ICS-43434 / MSM261S4030H0） | I2S1（SCK=15, WS=16, SD=17） | ⚠️ **进声孔在模块【背面】** ✗ 见坑 ② |
| 功放 | **MAX98357**（I2S） | I2S0（BCLK=5, LRC=6, DIN=7） | 直推小喇叭 ✓ |
| 喇叭 | 你手上的（约 8Ω 1~3W） | — | 量一下**直径与厚** ✓ |
| 指示灯 | **3 颗**（绿=4 / 蓝=12 / 红=13） | GPIO | 若用 5mm LED ✓ 见下 |

## 二、开孔尺寸（按实物微调 ✓）

### ① 屏窗口（最要紧 ✓）

```
SSD1306 0.96"：PCB 27.0 × 27.0 mm ｜ 玻璃约 26.5 × 19.5 mm
               可视区（发光）约 21.7 × 10.9 mm
⭐ 建议窗口：24 × 13 mm ✓（比可视区大 2mm 左右 ✓ 让边缘不压字 ✓）
⭐ 屏后加 1.5~2 mm 的台阶（凹槽）✓ 只让玻璃露出来 ✓
   否则 PCB 会顶住外壳 ✗ 屏会被压歪 ✓
```

### ② LED 孔

```
5mm LED：孔径 5.2 mm ✓（紧配 ✓ 不用胶 ✓）
想更柔和：孔内塞一小段白色导光柱 / 热缩管 ✓
三颗间距：建议 8~10 mm ✓（和状态表一一对应 ✓）
```

### ③ 麦克风（**最容易做错** ✗）

```
INMP441 这类模块：**进声孔在 PCB 的背面** ✗
→ 必须在外壳【背面】对着麦克风位开一个小孔（φ2~3 mm ✓）
→ 并且用一圈泡棉/硅胶把它和喇叭腔【隔开】✗（否则会啸叫 ✓）
```

### ④ 喇叭（**不开口就是闷罐** ✗）

```
喇叭正前方必须开【出声格栅】✓ 开孔率 ≥ 50% ✓
· 打一排 φ3 mm 的孔 ✓ 间距 4~5 mm ✓ 也行
· 或开一个大圆 + 一层薄纱网 ✓（更好看 ✓）
· 喇叭与外壳之间垫一圈泡棉 ✓ 防止共振杂音 ✓
```

### ⑤ USB-C（**千万别封死** ✗）

```
开口 ≈ 9.5 × 3.5 mm ✓（比口子大一点 ✓ 方便插线 ✓）
⭐ 用途：供电 + 烧录固件 ✓
   接下来你还要【反复烧固件】✗ 封死就等于每次拆壳 ✓
```

### ⑥ BOOT 键

```
⚠️ **2026-11-02 改**：外壳做好之后板载 BOOT 按不到了 ✗。
→ **另装一个外接按键**（IO21，一脚接 GND），外壳上开 **φ5~6 mm** 的孔装它。
短按 = 说一句，长按 3 秒 = 重启（等同原来的 RESET）。
（原来这里建议留 φ2~3 mm 牙签孔 —— 现在改成装真按键，手感好得多）
（进下载模式用 ✓ 平时不用 ✓）
```

### ⑦ 散热

```
ESP32-S3 满载约 0.5 W ✓ 不烫 ✓ 但建议底部/顶部各开几条 2 mm 缝 ✓
（尤其夏天 + 密闭盒 ✓）
```

## 三、⚠️ 四个会把现有成果弄坏的坑（按严重程度 ✓）

| # | 坑 | 后果 | 怎么做 |
|---|---|---|---|
| **1** | ⭐ **喇叭不开口 / 开孔太小** | 声音发闷 ✗ 且**变小** ✗ —— 你刚调好的音量 18/21 会听不清 ✓ | 出声格栅 **≥50% 开孔率** ✓ |
| **2** | ⭐ **麦克风孔和喇叭腔连通** | **啸叫**✗（麦克风收自己的声音 ✓）→ 现在能用的"按键说话"会废掉 ✓ | 麦克风孔开在**背面** ✓ + 泡棉隔离 ✓ + 孔的朝向别对喇叭 ✓ |
| **3** | ⭐ **USB-C 被封** | 每次烧固件要拆壳 ✗ | 留开口 ✓ |
| **4** | ⭐ **屏窗口做小 / 不做台阶** | 边缘压字 ✗（IP、音量条、状态都被裁掉 ✓） | 窗口 24×13 mm ✓ + 2mm 台阶 ✓ |

## 四、装进壳里之后，这两件事**可能要重调**（不是必须 ✓）

```
① 麦克风增益（MIC_GAIN，现在是 2）
   → 壳内回声更大 + 孔更小 ✗ → 说话可能偏小 ✓
   → 现场试：正常音量说话，看 /v1/asr 的识别率 ✓ 不行再调（2 → 3）✓

② 音量（现在是 18/21）
   → 密闭盒会让低音更强、整体更响 ✗
   → 装好后先跑一次 tools\演示前自检.py ✓ 听一遍 ✓
     ⚠️ 但别超过 21 ✓ 也别用网页调到很低 ✗（网页限 10~21 ✓）
```

## 五、打样前的 10 秒自查（打印一次不便宜 ✓）

```
[ ] 屏窗口 24 × 13 mm ✓ 且有 2mm 台阶 ✓
[ ] 三颗 LED 孔 5.2 mm ✓
[ ] 麦克风孔在【背面】✓ 且与喇叭腔隔离 ✓
[ ] 喇叭出声格栅 ≥50% 开孔 ✓
[ ] USB-C 开口 ✓
[ ] BOOT 小孔 ✓
[ ] 散热缝 ✓
[ ] 板子的**固定柱**按实物孔距做 ✓（用卡尺量 ✓ 别用网上的图 ✗）
[ ] 喇叭/麦克风的线**留够长度** ✓（组装时能翻过来 ✓）
[ ] 先打【一个薄壳试装】✓ 别直接打整壳 ✗
```

> ⭐ 最后一条最重要 ✓：**先打一个 2~3 mm 厚的平板试装**（只验孔位 ✓ 10 分钟 ✓）
> 孔位对了再打整壳 ✓ 一次成型 ✓ 省料也省时间 ✓
