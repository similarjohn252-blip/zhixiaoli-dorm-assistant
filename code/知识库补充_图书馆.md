# 图书馆速查

> 依据：2026-10-19 用户提供

## 一、一句话

图书馆**早上 8 点开门，晚上 10 点关门**；**扫脸进馆**；座位**不用预约**，直接去自习就行；
借书、查馆藏要在**知行理工**里查。

## 二、开放时间

- **上午 8:00 开门**
- **晚上 10:00 闭馆**

## 三、怎么进馆

- **扫人脸进入**（不用刷卡）

## 四、座位 / 自习

- **座位不需要预约**，直接去就可以自习
- 想找空教室自习（教室不是图书馆），去知行理工搜**本科生教务管理系统** →
  **信息查询** → **查询空教室** → 按想要的时间查

## 五、借书 / 查馆藏

- 借书相关的事，到**知行理工**里搜索**馆藏查询**
- 在那里面能查馆藏、查借阅情况、办借还
