## 0. 先说三个**必须修**的（不修就是 bug）

### 0.1 音量的地址写错了 → 现在点了会报 404

| | |
|---|---|
| **现象** | 点音量那个按钮，浏览器的开发者工具里出现 `POST /__removed_write_volume__` 返回 **404** |
| **原因** | 这个地址在服务端**从来不存在**，是个占位名 |
| **要改成** | `POST /v1/board/volume` **免 token** |
| **请求体** | `{"volume": 15}` 一个数字 |
| **服务端会返回** | `{"ok": true, "steps": 21, "volume": 15}` |
| **范围限制** | ⚠️ 服务端夹在 **10~21** 传 5 会被抬到 10 **别想着 0 静音**（防把板子调哑）|
| **怎么算改对** | 点按钮 → 板子屏幕上的音量数字变了，且页面显示的也是新值 |

### 0.2 放歌只播了"好的给你放…"，没有播歌

| | |
|---|---|
| **现象** | 说"放周杰伦的七里香"，听到的是一句"好的，给你放…"，然后就没有音乐 |
| **原因** | 服务端返回**两个**音频地址，你们页面只用了第一个 |
| **两个字段** | `audio_url` = **那句播报**（TTS）；`audio_url2` = **歌本身**（m4a） |
| **要改成** | **有 `audio_url2` 就播它**；没有才播 `audio_url` |
| **怎么算改对** | 说"放首歌，稻香" → 听到的是歌 不是那句播报 |

### 0.3 同一个音频地址会被浏览器缓存 → 听到上一次的声音

| | |
|---|---|
| **现象** | 连续问两句，第二句听到的却是**上一次回答**的声音 |
| **原因** | 浏览器规则：**音频地址没变就不重新加载**（不是服务端的锅）|
| **服务端已改** | 现在每次的播报文件名都不同（形如 `output_a8cc48_743638200.wav`）|
| **你们要做的** | 每次设音频地址时**加一个时间戳参数**，例如在地址后面拼 `?t=` 加当前毫秒（**这是防缓存的标准做法**）|
| **怎么算改对** | 连着问两句不同的 → 第二句听到的是**新回答** |

## 1. 建议加的功能（按值排 加不加都行 但第一条强烈建议）

### 1.1 ⭐ 工单台账 + **回执下载**（最值 也是最有说服力的一个）

**为什么**：演示时用户说一句"我们宿舍的灯坏了要报修"，服务端会**真的建一张工单**并返回单号。
如果页面能把台账**列出来**、并且**每一行能下载一张回执** 那就是"它真的办了事"的闭环证据
这比任何界面动画都有说服力 而且评委可以**当场点一下带走**

| | |
|---|---|
| **列台账** | `GET /v1/tickets` 免 token |
| **返回结构** | `tickets`（列表）+ `stats`（各状态计数）+ `status_text`（状态的中文映射 直接用 别自己写）|
| **每条工单的字段** | `id` 单号 / `room` 房间 / `category` 类别 / `status` 状态 / `ts` 受理时间 / `updated` 最后更新 / `note` 事由 |
| **下载回执** | `GET /v1/tickets/<单号>/receipt.txt` 免 token **浏览器会直接下载一个 txt** |
| **要做的** | 台账列表每行右边加一个"回执"链接 **用浏览器原生的下载方式就行** 不需要任何脚本 |
| **回执内容** | 单号 / 房间 / 类别 / 状态（中文）/ 受理时间 / 最后更新 / 事由 / 生成时间 / 一句提示 |
| **怎么算改对** | 页面上能看到工单列表 点"回执"→ 下载到一个 txt 打开单号对得上 |

⚠️ 一个提醒：台账里有**房号** 现在是演示数据 没问题
但如果以后接真实数据 → 页面上就不该显示完整房号 要脱敏

### 1.2 ⭐ "正在思考"的提示（这条今天才更需要）

**为什么**：我实测过平台延迟 —— **中位 6 秒、尾部能到 15 秒**。
页面如果这 6~15 秒什么都不显示 用户会以为坏了 会反复点

| | |
|---|---|
| **要做的** | 发出问题后立刻显示"正在问学校平台…（一般 5~8 秒）" 拿到结果后消失 |
| **加分项** | 超过 10 秒还没回 就把文案改成"这次有点慢，还在等" |
| **怎么算改对** | 问一句 → 立刻看到提示 不是白屏 |

### 1.3 每条回答标出**来源**和**耗时**

**为什么**：服务端其实已经在返回这两个信息 但页面没用
评委问"平台挂了怎么办" 你指着屏幕说"看，这里写着走了本地规则" 比嘴上说强

| | |
|---|---|
| **字段** | `source`（云端平台 / 云端平台·自愈 / 本地回退 / 本地台账 / 音乐）+ `timings`（各段耗时 单位秒）|
| **要做的** | 回答下面加一行小字：来源 + 平台那一段的秒数 |
| **怎么算改对** | 正常回答显示"云端平台" 平台超时时显示"本地回退" |

### 1.4 一键演示按钮（现场救命）

**为什么**：现场网络抖、或评委想自己试 点按钮比说话快

**用哪几句**（我今天实测了耗时 按最快排）：

| 按钮 | 问题 | 实测耗时 |
|---|---|---|
| ① | 我的报修进度怎么样了 | **1.7 秒** 最快 |
| ② | 一加一等于几 | **3.9 秒** |
| ③ | 我们宿舍的灯坏了要报修 | **5.2 秒**（会真建单 绿灯）|
| ④ | 咱们学校的校训是什么 | **6.3 秒** |

⚠️ **别放进按钮的两句**（会 11~14 秒 开场就慢很难看）：
- "你好呀"（闲聊）→ 实测 **12.7 秒**
- "今天几号" → 实测 **11.0 秒**
- "学校新出的晚归规定怎么算" → **13.9 秒**

### 1.5 板子状态 + 音量滑块

| | |
|---|---|
| **读状态** | `GET /v1/board` 免 token 返回 `online`（在线与否）/ `volume`（当前音量）/ `steps`（可用档位数）|
| **写音量** | `POST /v1/board/volume` 见 0.1 |
| **要做的** | 一个大绿点表示板子在线 红点表示离线 加一个音量滑块 |
| **怎么算改对** | 拔掉板子电源 → 几秒后变红点 插回去 → 变绿 |

## 2. 接口一览（都是**免 token** 的 浏览器直接就能调）

| 用途 | 方法 | 地址 |
|---|---|---|
| 文字问答 | POST | `/v1/chat` |
| 语音上传（板子用） | POST | `/v1/voice` |
| 板子状态 | GET | `/v1/board` |
| 调音量 | POST | `/v1/board/volume` |
| 工单列表 | GET | `/v1/tickets` |
| **回执下载** | GET | `/v1/tickets/<单号>/receipt.txt` |
| 服务端健康 | GET | `/v1/health` |
| 音频播放 | GET | `/audio/<文件名>` |

🔐 **要 token 的只有**：`/v1/device/*` 和 `/v1/memory*`
→ **页面别调这两个**（尤其别把 token 写进前端 会被看见）

## 3. 验收标准（改完自查这几条）

- [ ] 点音量按钮 → 不报 404 板子音量真的变了
- [ ] 说"放首歌" → 听到的是歌 不是"好的给你放…"
- [ ] 连问两句 → 第二句听到的是新回答 不是上一句
- [ ] 台账能看到工单 点"回执"能下载 txt
- [ ] 问一句立刻有"正在思考"提示 不是白屏
- [ ] 回答下面显示来源和耗时
- [ ] 拔板子电源 → 页面几秒内变红点
- [ ] 页面**没有**任何 token

## 4. 不要做的（⚠️ 都是会翻车的）

| 想法 | 为什么不行 |
|---|---|
| 显示"个人信息/记忆" | 那个接口要 token 把 token 放前端等于公开 里面还有房号 |
| 音量之外的控制（开关灯、重启板子）| 写操作 现场被点坏就完了 |
| 在浏览器里录音 | 复杂 而且按键说话已经够了 |
| 换主题 / 加动画 | 定格前 不加分 还容易弄坏 |

---

## 5. 一个提醒

页面现在的地址是**跟着浏览器地址走**的（同源 所以不用配任何服务端地址）
→ **不要双击 html 文件打开** 那样会变成 `file://` 请求全都失败
→ 正确打开方式：`http://192.168.137.1:5000/`（热点开着时这个地址永远不变）
