# 回复：音量控制接口（2026-10-15）

## 一句话

**接口给你了 ✓ 路径就用你建议的那个 ✓ —— 但加了一道边界：只允许 `10~21`** ✗

## 接口规格（按你的表 ✓ 只有「越界」多一个字段）

```
POST /v1/board/volume           ← 免 token ✓（这是你的核心诉求 ✓）
请求：{"volume": 15}

成功：200 {"ok":true, "volume":15, "steps":21}
越界：200 {"ok":true, "volume":10, "steps":21,
           "note":"已夹到安全区间 10~21（你给的是 0）"}      ← ⭐ 多这个 note 字段 ✓
非法：200 {"ok":false,"volume":null,"steps":21,
           "error":"volume 必须是 10~21 的整数"}
板子离线：200 {"ok":false,"error":"板子没响应"}

· 一律返回 200 ✓（与 /v1/board 风格一致 ✓ 不用 try/catch ✓）
· 返回里的 volume 是【读回板子的真实值】✓ —— 请用它渲染 ✗ 不要用你发出去的值 ✓
· 有 `note` 就显示出来 ✓（用户才知道数字为什么变了 ✓）
```

## ⭐ 为什么是 `10~21` 而不是 `0~21`（这条请你一定采纳 ✓）

```
它是【公开的写接口】✗ —— 任何能打开页面的人都能调 ✓
最坏情况不是隐私泄露 ✗，而是【演示现场把板子弄哑】✗✗

固件实测的音量曲线（不是我猜的 ✓）：
   vol=5  → -52 dB  【几乎无声】✗
   vol=15 → -13 dB  ✓
   vol=21 →   0 dB  ✓

→ 限制在 10~21 ✓：最坏情况只是"变小声"（10 ≈ -33dB，仍然听得清 ✓）不会哑 ✗✓
→ 真需要静音/更小 → 我们用**带 token 的管理接口** ✓（不在网页上开 ✗）
```

## 前端怎么接（约 10 分钟 ✓）

```js
// 读
const st = await (await fetch(CONFIG.SERVER + "/v1/board")).json();
// { online: true, volume: 15, steps: 21 }

// 写
const r = await (await fetch(CONFIG.SERVER + "/v1/board/volume", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ volume: slider.value })
})).json();
if (!r.ok) { /* 显示 r.error */ }
else {
  slider.value = r.volume;            // ⭐ 用【读回的值】✓ 它可能被夹过 ✓
  if (r.note) hint.textContent = r.note;   // ⭐ 有 note 就显示 ✓
}
```
