# 智小理 · 宿舍事务助手

一个放在宿舍里的**语音助手**：说一句 `Hi ESP`（或按一下按键）→ 电脑上的服务端识别 → 问校园平台（带知识库）→ 播报回答 + 控设备。
本仓库包含**电脑端服务端**、**ESP32 固件**、以及一路踩坑踩出来的**测试与文档**。

- 定位（比赛）：自由选题 · **管理服务智能体** · 智能应用 · 题目聚焦**宿舍事务**（报修 / 住宿规定 / 违规提醒 / 晚归报备）
- 技术栈：ESP32-S3（Arduino）＋ Python Flask ＋ 百度语音 ＋ 智小理平台（Dify 工作流）
- 现状总览：见 **[现状.md](现状.md)**（现在到底什么能用）、**[对外功能清单](对外功能清单.md)**（能做什么 / 不能做什么，都实测过）、
  **[待办总表](待办总表_2026-10-14.md)**（还剩什么没做）与 **[工程债对账](工程债对账_2026-10-14.md)**（每笔债的证据）

## 它能干哪几件事

1. **办事指路**（本地生成，2 秒内，平台挂了也照常）：报修 / 请假 / 报修进度 / 自习室 —— 告诉你去知行理工哪里办
2. **校园信息**（走平台 + 知识库）：校训、宿舍规定、晚归、考试纪律、校车四套时刻表、图书馆
3. **实时信息**：今天几号、星期几、现在几点、重庆天气
4. **课表与提醒**（2026-10-22）：网页上传教务处课表 PDF → 校对 → 每场课前 20 分钟提醒，到点先「叮咚」再播报；
   还能直接问「今天有课吗」「明天几节课」「下节课是什么」（2026-11-06 起，本地算、按单双周过滤）
5. **语音定闹钟**（2026-10-22）：「十秒后提醒我喝水」「八点提醒我开会」
6. **用户档案**（2026-10-22）：说「记住我大二计算机专业，英语较弱」，之后问「高数怎么复习」会顺着这个讲；
   学号手机号那一级**只存在本机、不进回答、不发平台**
6b. **语音唤醒**（2026-10-27）：说英文 `Hi ESP` 就能叫醒它，唤醒在芯片本地完成、不上传
6c. **说话前先应一声 / 按一下打断**（2026-10-27）：松手先说「好的」；它正在播报时按按键（外接 IO21，或板载 BOOT）立刻停下重听
7. **硬件**：一颗电源指示灯（GPIO11，通电常亮）、**外接按键（IO21）**、音量 10~21、提示音
   —— 短按 = 说一句，长按 3 秒 = 重启（板子装进外壳后 BOOT/RESET 按不到，见 §1.10）
   —— 三色灯和 OLED 屏幕已于 2026-10-27 去掉（省 400 KB，正是唤醒装得下的原因）

**全部功能已在真机上验过**（2026-10-29 首上板，2026-11-04 封盒复验）——
唤醒、录音识别、定闹钟、课表提醒、打断重说、填充语、外接按键，八项验收记录见
**[板子到手后做什么.md](板子到手后做什么.md)** 末尾的验收表。

## 三步跑起来（约 10 分钟）

> 前置：Windows ＋ Python（本项目用 `E:\Python\python.exe`）＋ 能上校园网
> **换一台干净电脑也能照这个走** （本项目专门为它写了 `tools\检查依赖.py`）

### 第 1 步 · 装依赖

```powershell
cd E:\天翼
E:\Python\python.exe -m pip install -r requirements.txt
```

（版本已**精确锁定** —— 装完想核对：`E:\Python\python.exe tools\检查依赖.py`）

### 第 2 步 · 配好 `.env`（**只有这一步需要你填东西**）

```powershell
cd E:\天翼
copy .env.example .env
notepad .env
```

要填三个（其余保持默认即可）：

| 变量 | 去哪拿 |
|---|---|
| `BAIDU_API_KEY` / `BAIDU_SECRET_KEY` | 百度智能云 → 语音技术 → 应用管理 |
| `ZHIXIAOLI_CLOUD_KEY` | 智小理平台后台 → 应用 → API 密钥 |

> `.env` 已被 `.gitignore` 排除 **绝不会进仓库** （项目还装了提交前护栏，见下）

### 第 3 步 · 启动

```powershell
E:\Python\python.exe code\run.py
```

看到这一行就成了：

```
监听: 0.0.0.0:5000  （ESP32 下载地址 http://<你的地址>:5000/audio/...）
```

- **这个窗口要一直开着** （关掉 = 板子和网页都连不上）
- 它会先做一次**启动自检**：缺配置会一次列全、端口被占会告诉你怎么查
- 验证：浏览器打开 `http://127.0.0.1:5000/v1/health` → 看到 JSON 就是通了

### 一条命令验证「真的没坏」

```powershell
cd E:\天翼
E:\Python\python.exe 全量测试.py
```

## 接板子（要做硬件演示时才需要）

1. **接线**：见 **[接线与使用说明](code/接线与使用说明.md)** §一（2026-10-27 起硬件是**一颗电源灯 GPIO11 + 麦克风 + 功放 + 按键**；该文档里 OLED 与三颗 LED 那几节只作历史参考，顶部有说明）
2. **固件配置**：复制 `code\sketch_oct8a_copy_20261008145732\secrets.example.h` → `secrets.h`，填 Wi-Fi 与服务端地址
3. **烧录**：⚠️ **必须整片烧**（含分区表和 3.19MB 唤醒模型），而且 IDE 的「分区方案」菜单要手动选 `ESP SR 16M` —— 它不读 `sketch.yaml`。最稳的命令见
   **[板子到手后做什么.md](板子到手后做什么.md)** 第 1 步（附「五条烧写记录」的核对清单）
4. **验证**：说 `Hi ESP` 或按一下外接按键再说一句 → **串口**出现 `[状态] …｜听到: …｜回复: …`、喇叭出声 = 全链路正常
   （2026-10-27 起没有屏幕了，状态一律看串口；详见 `板子到手后做什么.md`）

> 板子不在身边时，**服务端照样能跑** （网络接口全部可用，只是设备类接口会返回 `online:false`）

## 代码结构

```
code\
  run.py                启动入口（先启动自检 → 再监听）
  server\               服务端 20 个模块（每个文件头都写了"为什么这么做"）
    config.py           全部配置与路径（换网络/换端口只改 .env）
    brain.py            意图分流、动作映射、平台调用与自愈、本地话术
    app.py              Flask 路由（只做"接线"，30 条路由）
    memory.py           用户档案 + 短期记忆（写入收紧、分级、有选择的注入）
    profile_key.py      档案口令（PBKDF2 加盐哈希，只能在服务端那台电脑上设/重置）
    timetable.py        课表 PDF → 具体日期钟点（含作息表、单双周）
    reminders.py        课表提醒 + 闹钟的存储与"未来 48 小时"预览（SQLite）
    alarm.py            语音定闹钟的时间解析（相对/绝对/顺延）
    chime.py            提示音 + 人声拼成一个 wav
    remind_audio.py     只给 10 分钟内的提醒预生成音频
    speech.py           百度识别 / 合成（含 edge-tts 兜底）
    music.py            iTunes 30 秒试听：搜索 / 下载 / 格式兜底 + 旧音频轮转清理
    weather.py          重庆天气（高德）
    gpa.py              绩点换算（给平台工具用）
    device.py           板子代理（网页不直连板子的私有地址）
    tickets.py          报修台账（SQLite + WAL；10-19 起不再新建单）
    trace.py            链路追踪（request_id + 各段耗时 + JSON 日志）
    preflight.py        启动前自检（fail-fast）
  sketch_oct8a_copy_20261008145732\   固件（.ino + config.h 硬件调参 + secrets.h 网络密钥 + sketch.yaml）
tools\                  自测 / 诊断 / 维护脚本（27 个，含清理生成物.py / 固件备份.py / 回滚固件.py）
tests\                  pytest 快测试层（250 项，约 5 秒，不联网）
_材料\                  赛题原始材料（PDF 提取文本、手册、选题方向）
语音\                   运行时产物：播报音频、最近录音、放歌缓存、日志（已 gitignore）
```

## 三个最常踩的坑（详见接线说明的踩坑清单）

1. **改完服务端要重启** —— 老进程会一直用旧代码；用 `/v1/health` 的 `version` 一眼看出跑的是哪一版
2. **`curl.exe` / `Invoke-RestMethod` 发中文会乱码** —— 看起来像"后端全坏了" 测中文请用**浏览器或 Python**
3. **板子的 IP 固定、电脑的 IP 会变** —— 换网络后要同步 `ZHIXIAOLI_PUBLIC_HOST` 与固件里的 `secrets.h`
