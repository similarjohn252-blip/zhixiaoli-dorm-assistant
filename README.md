# 智小理 · 宿舍事务助手

一个放在宿舍里的**语音助手**：板子按住说话 → 电脑上的服务端识别 → 问校园平台（带知识库）→ 播报回答 + 控设备。
本仓库包含**电脑端服务端**、**ESP32 固件**、以及一路踩坑踩出来的**测试与文档**。

- 定位（比赛）：自由选题 · **管理服务智能体** · 智能应用 · 题目聚焦**宿舍事务**（报修 / 住宿规定 / 违规提醒 / 晚归报备）
- 技术栈：ESP32-S3（Arduino）＋ Python Flask ＋ 百度语音 ＋ 智小理平台（Dify 工作流）
- 现状总览：见 **[待办总表](待办总表_2026-10-14.md)**（还剩什么没做 ✓）与 **[工程债对账](工程债对账_2026-10-14.md)**（每笔债的证据 ✓）

## 三步跑起来（约 10 分钟）

> 前置：Windows ＋ Python（本项目用 `E:\Python\python.exe`）＋ 能上校园网
> **换一台干净电脑也能照这个走** ✓（本项目专门为它写了 `tools\检查依赖.py` ✓）

### 第 1 步 · 装依赖

```powershell
cd E:\天翼
E:\Python\python.exe -m pip install -r requirements.txt
```

（版本已**精确锁定** ✓ —— 装完想核对：`E:\Python\python.exe tools\检查依赖.py` ✓）

### 第 2 步 · 配好 `.env`（**只有这一步需要你填东西**）

```powershell
cd E:\天翼
copy .env.example .env
notepad .env
```

要填三个（其余保持默认即可 ✓）：

| 变量 | 去哪拿 |
|---|---|
| `BAIDU_API_KEY` / `BAIDU_SECRET_KEY` | 百度智能云 → 语音技术 → 应用管理 ✓ |
| `ZHIXIAOLI_CLOUD_KEY` | 智小理平台后台 → 应用 → API 密钥 ✓ |

> `.env` 已被 `.gitignore` 排除 ✓ **绝不会进仓库** ✓（项目还装了提交前护栏，见下 ✓）

### 第 3 步 · 启动

```powershell
E:\Python\python.exe code\run.py
```

看到这一行就成了 ✓：

```
监听: 0.0.0.0:5000  （ESP32 下载地址 http://<你的地址>:5000/audio/...）
```

- **这个窗口要一直开着** ✓（关掉 = 板子和网页都连不上 ✗）
- 它会先做一次**启动自检** ✓：缺配置会一次列全、端口被占会告诉你怎么查 ✓
- 验证：浏览器打开 `http://127.0.0.1:5000/v1/health` → 看到 JSON 就是通了 ✓

## 接板子（要做硬件演示时才需要）

1. **接线**：见 **[接线与使用说明](code/接线与使用说明.md)** §一（含三颗 LED 的 GPIO 与电阻 ✓）
2. **固件配置**：复制 `code\sketch_oct8a_copy_20261008145732\secrets.example.h` → `secrets.h`，填 Wi-Fi 与服务端地址 ✓
3. **烧录**：用 Arduino IDE 打开那里的 `*.ino` 直接烧 ✓（编译参数已固化在 `sketch.yaml` ✓，不用手点菜单 ✓）
4. **验证**：按住 BOOT 说一句 → 屏幕出现"听到/回复/云端平台"、喇叭出声 = 全链路正常 ✓

> 板子不在身边时，**服务端照样能跑** ✓（网络接口全部可用，只是设备类接口会返回 `online:false` ✓）

## 代码结构

```
code\
  run.py                启动入口（先启动自检 → 再监听 ✓）
  server\               服务端 10 个模块（每个文件头都写了"为什么这么做" ✓）
    config.py           全部配置与路径（换网络/换端口只改 .env ✓）
    memory.py           长期记忆 + 短期记忆（含"按需注入"规则 ✓）

tools\                  自测 / 诊断 / 维护脚本（17 个，见下）
_材料\                  赛题原始材料（PDF 提取文本、手册、选题方向）

```

## 三个最常踩的坑（详见接线说明的踩坑清单）

1. **改完服务端要重启** ✗ —— 老进程会一直用旧代码；用 `/v1/health` 的 `version` 一眼看出跑的是哪一版 ✓
2. **`curl.exe` / `Invoke-RestMethod` 发中文会乱码** ✗ —— 看起来像"后端全坏了" ✓ 测中文请用**浏览器或 Python** ✓
3. **板子的 IP 固定、电脑的 IP 会变** ✓ —— 换网络后要同步 `ZHIXIAOLI_PUBLIC_HOST` 与固件里的 `secrets.h` ✓
